# Annual reports

`十年候选_2016_2025分红年报PDF/`保留旧项目中11家正式公司的2016–2025年报：
中国电信、中国移动、伊利股份、华润江中、国投电力、川投能源、海信家电、
海尔智家、美的集团、腾讯控股和长江电力。

`official_backfill_v1/`保存其余56家从巨潮资讯和港交所披露易取得的官方年报、
原始检索响应、逐公司manifest、SHA-256及总覆盖账本。截至2026-08-02新增526份
PDF（巨潮419份、港交所107份）；连同旧归档，67家公司覆盖状态均为`VERIFIED`。
九家公司因上市年限或官方可检索历史不足而少于10份，实际年份以manifest为准，
不补造缺失财年。

这里的`VERIFIED`仅表示官方PDF通过文件头、页数和哈希校验，不表示股息、股本、
回购或现金流字段已结构化为`VALID`。详细运行与复核命令见
`../../../docs/annual_report_backfill.md`。
